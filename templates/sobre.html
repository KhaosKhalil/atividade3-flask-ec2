Sobre o projeto

Este site é a entrega da {{ atividade }}. O objetivo é tirar a aplicação do ambiente local e publicá-la na nuvem.

Etapas do deploy

  1. Instância EC2: Ubuntu Server, tipo do nível gratuito, nome webServer-seunome.
  2. Security Group: entrada liberada para SSH (22/tcp) e Flask (5000/tcp).
  3. Preparação: apt update, apt upgrade e instalação de python3-venv e python3-pip.
  4. Projeto: pasta no diretório do usuário, git clone e criação do ambiente virtual.
  5. Dependências: pip install -r requirements.txt.
  6. Execução: Gunicorn em 0.0.0.0:5000 como serviço do systemd, que continua rodando após fechar o SSH.

Tecnologias

  • Python
  • Flask
  • Jinja2
  • Gunicorn
  • Ubuntu
  • AWS EC2
