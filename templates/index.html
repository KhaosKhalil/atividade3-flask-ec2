Servidor Web Flask na AWS EC2

Aplicação Flask publicada em uma instância Ubuntu na nuvem da AWS, acessível pelo IP público.

Como foi feito

Amazon EC2

Máquina virtual Ubuntu Server criada no nível gratuito, com par de chaves para acesso SSH.

Security Group

Regras de entrada liberando a porta 22 (SSH) e a porta 5000 (Flask).

Ambiente virtual

Dependências isoladas em um venv e listadas no requirements.txt.
